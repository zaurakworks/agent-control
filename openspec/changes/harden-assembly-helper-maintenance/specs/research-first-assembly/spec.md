## Purpose

规定 Agent 装配决定何时需要当前外部证据，以及如何选择、记录证据并将其与仓库内部事实分开。

## ADDED Requirements

### Requirement: 依赖外部事实的决定必须先调研
当变更依赖外部标准、客户端行为、当前版本、安全属性、兼容性结论或候选能力资产时，装配助手 MUST 在作出决定前调研。

#### Scenario: 外部标准控制变更
- **WHEN** 维护者要求依据当前 Agent Skills 格式修改 Skills
- **THEN** 助手在提出方案或编辑运行时合同前查阅当前官方规范

#### Scenario: 仓库事实可在本地恢复
- **WHEN** 请求仅依赖仓库内已有文件和可恢复行为
- **THEN** 助手使用仓库证据，不为满足流程形式而浏览网络

### Requirement: 外部事实由一手来源控制
装配助手 MUST 优先使用标准、官方文档、官方源码和 release notes、维护者 RFC 或 issue，以及可复现实验；第三方摘要只能作为线索。

#### Scenario: 第三方文章与官方来源冲突
- **WHEN** 第三方来源与适用的官方规范或当前官方文档冲突
- **THEN** 助手以官方来源为控制事实，并在冲突影响决定时记录差异

### Requirement: 调研证据必须可审查
对每个控制装配决定的外部事实，装配助手 MUST 报告来源、可得的适用版本或日期、被支持的事实、推断边界和剩余未知。

#### Scenario: 运行兼容性没有直接观察
- **WHEN** 官方文档说明支持某客户端，但没有观察到目标客户端真实运行
- **THEN** 助手将文档兼容性与实际生效态证据分开报告
