## 原总图横向定位与原则（搬迁）

> 迁移来源：以下段落由 [`00-map.md`](./00-map.md) 原“领域”与“共同建设原则”按 [关联 #44（规则只加不减的收敛实施）总图索引化决定](https://github.com/Eridanus117/agent-control/issues/44#issuecomment-5258111511)原文迁入；“上述四个领域”仍指总图路由及 [`02-long-horizon-work.md`](./02-long-horizon-work.md) 所列四域，只置换承载位置。

资源与运营是横向保障领域：它服务于上述四个领域的取舍和运行，不替代任何一个原始诉求。

**共同确认**：可观测数据能帮助判断是否升级能力，但获取数据本身也有成本；如果获取成本高于预期决策价值，可以降低精度、延后或放弃获取。

## 当前问题

系统如果不知道可用资源、消耗和恢复时间，就无法可靠判断任务是否应当启动、继续、降级、并行或暂停，也无法判断某项能力建设是否值得。

## 需要关注的资源

1. 当前上下文已经使用和可能剩余的容量，以及上下文压缩情况；
2. 各模型的额度、速率限制和重置时间；
3. 订阅、赠送额度、重置券或其他可用权益及金钱成本；
4. 可用并发容量；
5. 延迟、失败率和重试成本；
6. 任务预计消耗的资源；
7. 人的注意力与对齐成本。

## 期望结果

系统能使用足够可靠的资源信息安排工作、控制成本，并把“继续投入、降低规格、延后或停止”作为可比较的选择。

## 当前资源边界

当前这台 Windows 电脑上的 Codex 和 Claude 主要服务于本系统的建设，因此它们的可用 Token 和执行容量可以用于这项工作。私域工作使用另外的模型和额度；私域内容与本系统仍需保持边界，不能因为资源可用就自动进入本系统。

## 可信度规则

资源数据必须明确区分：

- 权威且精确：由产品、账户或可靠接口直接提供；
- 估算：有依据但不是产品提供的精确值；
- 未知：当前无法可靠取得。

Agent 不得把估算写成精确值，也不得编造账户额度、重置时间或上下文剩余量。

## ROI 原则

资源观测本身也需要成本。只有当数据能以合理成本改善决定时才值得获取；获取成本过高时，可以使用较粗的估算、延后采集，或明确保留为未知。

## 资源投入原则

> 来源：负责人于 2026-08-12 批准[关联 #120（资源投入决策规则）120-D1=C 两层承载](https://github.com/Eridanus117/agent-control/issues/120#issuecomment-5261662312)；版本化实施合同为[关联 #128（资源投入规则两层承载落地）](https://github.com/Eridanus117/agent-control/issues/128)。本节只保存跨 Provider、跨任务稳定的原则；派发前的动作顺序由 `orchestrated-collaboration` 引用本节执行，不在这里复制工作流、证据历史或动态阈值。

1. **价值门先于额度。** 资源是约束与加速条件，不是工作来源。只有当前授权内、能形成稳定交付并独立验收、即使没有额度期限也值得完成，且预期价值高于派发、恢复、审查、整合与负责人判断总成本的任务，才可进入投入比较；不得为达到并发数或消耗比例制造、拆碎或提前启动工作。
2. **新鲜度与未知值决定资源理由是否成立。** 只有来源正常、窗口身份一致且采集时间确实前进的读数，才能支持跨时点资源判断；陈旧、不可归因或无法可靠取得的值保持未知。读数不合格时，只撤销“基于额度扩产”的理由，不停止已有价值、合同与所有权支持的工作。
3. **并发上限取最先到来的真实瓶颈。** 可独立并行的就绪工作深度、可排他的写入所有权、任务与 Provider 适配、独立验收及整合容量、负责人注意力、依赖和风险保护，任一项都可以先于账户余额成为上限。开放事项总数、可用 Session 数、单 Session Token 或额度利用率均不能单独触发派发。
4. **实验与交付质量优先于消耗速度。** 加派不得破坏预注册实验的并发／隔离门、顺序约束、审查独立性或负责人专属决定；失败、碰撞、返工和注意力成本上升时，应先维持或停止新增派发。临期资源只能在价值与适配已经成立的候选之间帮助排序，不能把低价值工作升级为真实工作。
5. **保持人工、事件驱动和可退出。** 当前资源投入决定由持有任务合同与写入所有权的 Session 在自然事件处人工复核；它可以加派、维持或停止新增派发，但不因此获得中止活动 Session、撤销合同、自动消费权益或执行其他破坏性动作的权限。本原则不建设固定频率轮询、自动派发、自动停止或动态阈值；如果规则持续不能改变决定、记录成本高于价值，或诱发低价值拆单、隐瞒返工、少问必要问题或破坏实验门，就回到逐案人工判断并重新设计。

**守恒律置换记录**：本节把原来只写“取得资源数据是否值得”的 `ROI 原则` 扩展为“哪些任务值得投入、哪些资源证据足以改变投入、什么限制并发、何时保持人工并退出”的完整原则层；置换此前由协调者临场综合、且长期资产中没有成文承载的隐含判断。动作层只引用本节并保留 R1–R6 顺序，避免在权威与 Skill 复制同一套证据、阈值或状态机。

本轮没有决定具体监控方式、数据接口、仪表盘、自动调度器或自动停止规则。
