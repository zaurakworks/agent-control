# 当前执行与状态边界

## 地位

本文件保存当前执行装配、交互激活和活动状态的稳定公共政策。它不保存任务进度、运行实例、实验过程或下一步，也不要求读取 private 研究仓才能理解。

## 当前执行是装配控制对象

一次当前执行只获得其目标、输入、约束、上下文、能力和权限所需的最小充分配置。控制对象首先是这次执行，不是固定阶段名、永久角色或历史 Session。

目标、合同状态依据、能力、权限、风险或产物发生实质变化时，必须重新判断装配；不得因为仍在同一聊天、Session、分支或阶段名称下，就继续沿用旧能力面。额外、未声明的能力必须由 closure 或 launch 门拒绝，不能通过提示词约定视为已隔离。

## 活动状态不由仓库本地文件承载

仓库本地文件不得作为任务队列、当前进度、阶段状态、ownership、lease 或跨执行运行态的合同状态依据。版本化代码、测试、政策、静态合同、能力配置、不可变审计证据和可删除缓存可以保存在文件中，但“文件存在”不能证明事项活动、权限有效或交付已验收。

活动工作状态必须绑定具有稳定 URI 和可观察版本的外部 WorkItem。静态本地合同必须记录该绑定，不能自行成为活动状态源；缺少稳定远端绑定时不得激活执行。

## 自由对话与显式激活

自由对话、探索、建议、枚举候选或建立 proposal 不自动形成 Issue、交付承诺或实施授权。只有负责人明确声明进入正式工作，且合同、能力和写入所有权没有冲突时，才进入执行。交互模式、终端名称、模型身份和可用工具本身都不产生权限。
