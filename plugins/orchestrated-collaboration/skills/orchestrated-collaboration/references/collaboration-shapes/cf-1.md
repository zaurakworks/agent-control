# CF-1｜受监督单 Worker

## 身份与来源

- `shape_id`：`CF-1`；版本：`0.1.0`；维护者：agent-plugins 协作域。
- 来源：[关联 #44（实施 D1–D6 与授权内动作）第二张波次回执](https://github.com/Eridanus117/agent-control/issues/44#issuecomment-5255737976)；许可／私域：仓内自有，公开可移植；核验时间：2026-08-11。

## 目的与类型

- 要减少的未知／决定：单一任务是否值得用独立上下文执行；类型：执行拓扑。
- 预期效果：Worker 承担边界清楚的执行包，协调者保留验收与决定权。

## 进入条件

- 可观察信号：一个可独立交付任务、范围可排他、协调者能独立复核；前置证据：委派收益高于合同恢复成本。
- 输入：自足派发合同与完成判据；工具／上下文：真实协调后端与两个独立上下文。

## 硬门与禁用

- 明示同意：已有多 Session 委派授权；授权：Task／Dispatch、文件与远端动作必须在合同内。
- 风险／写入所有权：Worker 独占其范围，协调者只验收；不适用：边界会扩张、无法独立验收或任务存在多个无依赖切片。

## 执行定义

- 步骤／执行资产：协调者派发自足合同，Worker 执行并按三句摘要报告，协调者复核交付、远端事实与剩余项。
- 输出：可追踪交付与验收事实；完成条件：报告被独立核验，资源已按当前后端合同复用或释放。

## 成本画像

- 墙钟：中低；Token／工具调用：中（未核验推断，双上下文）；协调 Agent：1；负责人问询：通常低；维护成本：低到中。

## 风险与回退

- 主要失败方式：任务落点竞态、Task／Dispatch 身份混淆、完成报告假阳性；可逆性：中高；失败门：落点、所有权或远端事实无法核清。
- 恢复路径：只恢复同一派发，先核验再重试；未核清前不创建重复执行者。

## 组合关系

- 前序：CF-0 或人工选型；后序：CF-7 的起草／修订段；冲突：同一层与 CF-0、CF-2 至 CF-4 冲突；最多组合深度：2。

## 控制规则

- 继续：边界与验收保持自足；降级：收益转负时退 CF-0；升级：出现多个无依赖排他切片时转 CF-2。
- 换路：协调者不能独立验收时先重建合同；退出：验收与资源收口完成；翻转条件：合同恢复成本超过独立上下文收益。

## 有效性证据

- 来源等级：一手来源核验；能力证据等级：M1 当前交付验收；适用环境：本机 Orca 协调的 Agent 系统任务。
- 成功样本：第二张波次中的非中心单 Worker 完整闭环；失败样本：回车竞态与身份混淆；未知：逐形态 Token 与外部任务表现。

## 维护

- 失效条件：协调后端生命周期或派发身份语义变化；下次最少复核：单列一次恢复、验收和 Token 成本。
- 替代者：CF-0、CF-2；选择级别：人工、按需，只在相同边界下建议。
