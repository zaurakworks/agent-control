# CF-0｜单 Session 直做

## 身份与来源

- `shape_id`：`CF-0`；版本：`0.1.0`；维护者：agent-plugins 协作域。
- 来源：[关联 #44（实施 D1–D6 与授权内动作）S5 探测批](https://github.com/Eridanus117/agent-control/issues/44#issuecomment-5254413472)；许可／私域：仓内自有，公开可移植；核验时间：2026-08-11。

## 目的与类型

- 要减少的未知／决定：一个清楚、可回退任务是否值得承担协作税；类型：执行拓扑、普通路径。
- 预期效果：以最低协调成本形成合同指定的可重读交付物。

## 进入条件

- 可观察信号：单一交付物、工作图近似直线、当前 Session 已有完整上下文；前置证据：排他写入权与成功条件清楚。
- 输入：任务合同、验证面；工具／上下文：一个 Session 能覆盖执行与自审。

## 硬门与禁用

- 明示同意：普通授权内执行不新增同意门；授权：只使用当前合同已有授权，形态本身不扩权。
- 风险／写入所有权：必须排他；不适用：共享写入、产品决定、难回退动作或合同要求独立审查。

## 执行定义

- 步骤／执行资产：同一 Session 恢复合同、执行、验证并形成远端交付；输出：合同指定的唯一交付物。
- 完成条件：交付可重读，实际运行、未运行、缺口与副作用均已说明。

## 成本画像

- 墙钟：低；Token／工具调用：低（未核验推断，单上下文）；协调 Agent：0；负责人问询：只来自合同决定门；维护成本：低。

## 风险与回退

- 主要失败方式：上下文盲点、长任务压缩、单点停滞；可逆性：高；失败门：同源漏检或等待成本超过一次派发成本。
- 恢复路径：加一个只读复核者，或升级 CF-1。

## 组合关系

- 前序：普通问题界定；后序：CF-7 的起草段；冲突：与 CF-1 至 CF-4 不能同时作为同一层拓扑；最多组合深度：2。

## 控制规则

- 继续：单 Session 仍能低成本完成；降级：本卡已是普通路径；升级：等待、上下文或独立性收益变高时转 CF-1。
- 换路：出现可排他无依赖切片转 CF-2；退出：交付完成即退出；翻转条件：独立复核预期收益高于协作成本。

## 有效性证据

- 来源等级：一手来源核验；能力证据等级：M1 当前交付验收；适用环境：本机 Agent 系统的清楚只读探测。
- 成功样本：S5 五项探测由协调 Session 直接完成；失败样本：无逐形态记录；未知：独立墙钟与 Token 分账。

## 维护

- 失效条件：连续出现同源漏检或恢复失败；下次最少复核：下一次同类直线任务记录是否需要外加复核。
- 替代者：CF-1、普通路径加只读复核；选择级别：人工、按需，只在相同边界下建议。
