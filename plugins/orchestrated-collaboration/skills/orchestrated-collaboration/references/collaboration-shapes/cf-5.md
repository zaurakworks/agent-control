# CF-5｜攻防面板＋交叉裁决

## 身份与来源
- `shape_id`：`CF-5`；版本：`0.2.0`；维护者：agent-plugins 协作域。
- 来源：[关联 #66（权威与 Skill 资产攻防审计）](https://github.com/Eridanus117/agent-control/issues/66)与[关联 #100（夜间新增资产攻防审计）C7 裁决](https://github.com/Eridanus117/agent-control/issues/100#issuecomment-5259393664)；许可／私域：仓内自有，公开可移植；核验时间：2026-08-12。

## 目的与类型
- 要减少的未知／决定：为 APS 重型攻防提供角色拓扑、所有权与 GitHub 交付适配；类型：质量机制；预期效果：方法语义单一且角色来源可复核。

## 进入条件
- 可观察信号：APS 已选重型攻防；前置证据：独立上下文可用且净收益为正；输入：APS 阶段合同与攻击面；工具／上下文：排他 Session、远端评论面与协调后端。

## 硬门与禁用
- 明示同意：已有重型多 Session 授权；授权：角色交付不产生实施权；风险／写入所有权：角色排他写评论，协调者单写综合；不适用：无法独立或排他分区。

## 执行定义
- 角色拓扑与所有权：至少四个独立 Agent／Session；首轮至少两个攻击角色，次轮至少两个未参与首轮的裁决角色，其中一名裁决者单写综合。
- 交付适配：每个角色一条自足 Issue 评论，协调者按来源链接综合；轮次、必答结构、裁决与停止条件只执行[APS 攻防协议](../../../../../adaptive-problem-solving/skills/adaptive-problem-solving/references/adversarial-review.md)。

## 成本画像
- 墙钟：1–2 波次；Token／工具调用：很高；协调 Agent：至少 4；负责人问询：通常 0；维护成本：中高。

## 风险与回退
- 主要失败方式：角色重叠、综合多写或来源不可绑定；可逆性：中高；失败门：独立性或所有权不可证；恢复路径：重分受影响角色，无法隔离则退回轻量预演。

## 组合关系
- 前序：APS 选择重型攻防；后序：ROI、补证或 CF-7；冲突：与 CF-6 不同时审同一决定；最多组合深度：2。

## 控制规则
- 继续：角色与交付独立；降级：单 Session；升级：只增加分区明确的角色；换路：APS 改选方法；退出：APS 停止门；翻转条件：独立成本高于收益。

## 有效性证据
- 来源等级：一手来源核验；能力证据等级：M0 实现完成；适用环境：高影响 Agent 系统权威与 Skill 审计。
- 被验收主张与等级统一读取[多视角攻防方法卡](../../../../../adaptive-problem-solving/skills/adaptive-problem-solving/references/method-registry/cards/multi-perspective-adversarial-review.md)；成功样本：无完整样本，关联 #66 只有一名第二轮裁决者。失败样本：无独立完整记录；未知：跨对象净收益与 Token 分账。

## 维护
- 失效条件：APS Agent 下限、独立性或交付合同改变；下次最少复核：角色来源、冲突与可恢复性；替代者：单 Session 预演、普通审查；选择级别：M0，仅人工选用。
