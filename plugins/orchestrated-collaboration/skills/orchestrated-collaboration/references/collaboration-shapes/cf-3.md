# CF-3｜联邦子树／局部协调者

## 身份与来源

- `shape_id`：`CF-3`；版本：`0.1.0`；维护者：agent-plugins 协作域。
- 来源：[关联 #44（实施 D1–D6 与授权内动作）第二张波次回执](https://github.com/Eridanus117/agent-control/issues/44#issuecomment-5255737976)中的非中心派发样本；许可／私域：仓内自有，公开可移植；核验时间：2026-08-11。

## 目的与类型

- 要减少的未知／决定：一个自足父 Issue 子树能否由局部 Session 端到端驱动；类型：执行拓扑。
- 预期效果：降低永久中央协调瓶颈，同时让角色仍由合同与所有权决定。

## 进入条件

- 可观察信号：子树范围、成功条件与写入面自足；前置证据：父级允许局部协调，局部净收益为正。
- 输入：远端父合同、原生子图与活动占用；工具／上下文：局部协调者可恢复并验收整个子树。

## 硬门与禁用

- 明示同意：父合同已有局部协调授权；授权：不得扩大父目标、跨出子树或保留永久角色。
- 风险／写入所有权：已有活跃驱动者时加入其协调；不适用：跨域共享写入不可分或出现负责人专属决定。

## 执行定义

- 步骤／执行资产：恢复远端父合同，局部选切片，在子树内使用 CF-1／CF-2，把交付与未满足条件写回父级后退出。
- 输出：可恢复子树状态与交付来源；完成条件：父级能仅凭远端事实继续驱动。

## 成本画像

- 墙钟：中；Token／工具调用：中高（未核验推断，含父合同恢复）；协调 Agent：1+；负责人问询：低；维护成本：中。

## 风险与回退

- 主要失败方式：影子协调者、竞争 Run、父级回写缺失与双重状态；可逆性：中；失败门：出现跨域共享写入或产品决定。
- 恢复路径：停止局部派发，把当前事实交回既有父级驱动者。

## 组合关系

- 前序：自足父 Issue 合同；后序：父级回收；冲突：同一子树存在另一个活跃驱动者；最多组合深度：2。

## 控制规则

- 继续：子树边界与局部收益保持成立；降级：收益转负时转 CF-1；升级：自治子树增多且边界可分时转 CF-4。
- 换路：跨域决定上提父级；退出：回写父级后退出局部角色；翻转条件：子树不再自足或恢复成本超过中央等待成本。

## 有效性证据

- 来源等级：一手来源核验；能力证据等级：M1 当前交付验收；适用环境：本机 Agent 系统父子 Issue 工作流。
- 成功样本：一个完整非中心派发与验收样本；失败样本：无独立完整失败记录；未知：中断恢复与跨 Provider 样本。

## 维护

- 失效条件：角色或 Issue 子树所有权规则变化；下次最少复核：补一个中断恢复样本与一个跨 Provider 样本。
- 替代者：CF-1、现有父级驱动者；选择级别：人工、按需，不外推为默认拓扑。
