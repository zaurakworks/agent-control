# 协作形态卡索引

本目录是 `orchestrated-collaboration` 的按需形态登记面，不是第二个控制器，也不自动选择形态。主 Skill 先用五项输入作人工判断，再只读取命中的少量卡；证据、成本或边界变化时按卡片规则降级、换路或退出。

同一工作层只选一种执行拓扑；质量／决定机制只在硬门成立时叠加；阶段承载只处理真实前后依赖。任何卡片都不产生同意、授权、写入所有权、产品采用或长期平台承诺。
