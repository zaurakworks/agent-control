# 行动前事实与决定价值门

> APS 在首次实质行动前加载本文件并运行 G1；形成负责人动作前再运行 G2；只有 G2 证明真实阻塞后才运行 G3。未到相应分支不执行后续门。完成后返回 `../SKILL.md`。

本文件是 G1–G3 的唯一规范正文；其他 Skill 和形态卡只路由，不复制判据。

1. **G1｜实测或未知。** 能力、权限、网络、版本、资源新鲜度或工具状态主张，只要会改变做不做、下一动作、执行者或工具就触发；有低成本、安全、只读或易回退的直接探针则运行并记录对象、环境／版本、时间、探针和结果。探针不可得、昂贵、有副作用或需新增权限，就写“未知”，走可回退普通路径并登记翻转条件。直接证据可得时不用记忆或转述代替；不复测普通背景事实，也不授权安装、改凭据或宿主环境。
2. **G2｜无回复五维反事实。** 创建负责人请求或投影等待前，写明“负责人暂不回复”的普通路径，比较**下一动作、授权边界、风险暴露、资源投入或总成本、不可逆或有时限的机会**。五项均相同就不形成负责人动作、不投影等待，在授权内继续并保存推荐、置信、最强反方和翻转条件；任一不同才进入现有负责人决定协议。拿不准不自动升级：低影响可回退则保持未知；潜在损失高、默认继续扩大暴露或时限机会可能消失，就写明差异。沉默不是授权。
3. **G3｜三方审阅经济门。** 只有 G2 证明决定真实阻塞、现有替代授权覆盖该决定，且解除阻塞价值高于三席与时间盒总成本，才评估 `orchestrated-collaboration` 的 `references/collaboration-shapes/cf-6.md`；否则走负责人直接决定或普通路径。CF-6 的身份、密封、裁决和授权合同仍归其形态卡，结果不扩张授权。

迭代事件把证据／未知、普通路径与差异、授权、翻转条件和成本写入现有回执；普通任务只留解释选择的短记录。判据在行动前预注册，运行后只对照；验收同时看漏报、返工、核验成本和负责人注意力，不以请求数下降替代。
