# 受限调研：研究、选项、计划

> 仅在 APS 已归型为 P3 并选择受限调研时加载。完成或命中停止条件后返回 `../SKILL.md`；本文件不是独立控制器。

## 进入与停止

开始前说明调研支持哪个决定、哪些证据会翻转判断、范围、成本上限和停止条件。存在当前知识时先走知识维护；取得足以改变或稳定决定的证据、达到成本上限，或继续查找不再改变判断时收口。

## 三层证据分区

1. **研究层**：把事实、约束和未知分开。每条会影响决定的主张标注来源等级：`本次直接验证`、`一手来源核验`、`二手转述`、`未核验推断`；同时记录对象、版本／时间、环境和适用边界。等级说明核验距离，不替代来源质量判断。低成本直接验证或一手来源可得时，不用二手转述冒充已核验前提。
2. **选项层**：形成至少两个可信方案，比较架构适配、依赖假设、主要代价与风险及各自验证方式。确实没有第二个可信方案时列出已排除方向及证据，不为凑数伪造备选；“维持现状”只在确实可行时作为方案。推荐指出证据等级和翻转条件。
3. **计划层**：把选中方案转换成可检验行动，列出实际要运行的命令或检查、暂不运行项与理由、失败门、风险、开放问题和完成定义。每个关键假设至少对应一个验证面；未执行项和剩余缺口不能被“研究完成”或计划文本掩盖。

这三层是证据分区，不是 `research.md → options.md → plan.md` 的强制文件链。来源等级回答单条研究主张从哪里来，不改变整个能力的产品证据等级。
