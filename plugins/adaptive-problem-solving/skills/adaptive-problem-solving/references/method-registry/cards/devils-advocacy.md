# 反方论证（Devil's Advocacy）

## 身份与来源
- `method_id`：`devils-advocacy`；版本：`0.1.1`；维护者：agent-plugins。
- 来源：CIA《A Tradecraft Primer》Devil's Advocacy；许可／私域：公开一手来源的独立改写，未复制原文；核验时间：2026-08-11。

## 目的与类型
- 要减少的未知／决定：为占主导的判断构造最强可信反方，暴露证据与逻辑薄弱处；主类型：P4；次类型：P5。
- 预期效果：把“有人不同意”转为可复核的反论证与翻转条件。

## 进入条件
- 可观察信号：团队／Agent 已明显收敛到一个方向，反方未被认真表达；前置证据：主结论与依据。
- 输入：主结论、证据、边界；工具／上下文：单 Session 可轻量运行，重要决定宜由独立者执行。

## 硬门与禁用
- 明示同意：内部自审无需；授权：反方不授权替代方案实施。风险／写入所有权：独立复核者只读。
- 不适用：对象尚未明确、反方只是无证据怀疑，或低风险可逆动作反馈更快。

## 执行定义
- 步骤／执行资产：以最强可信反方立场重述结论，选取证据与推理断点，提出能使反方成立的观察，并由原任务回收。
- 输出：反方论证、主张受损程度与翻转条件；完成条件：反方达到可被支持或反驳的自足形状。

## 成本画像
- 墙钟：15–40 分钟；Token／工具调用：低至中；协调 Agent：0–1；负责人问询：0；维护成本：低。

## 风险与回退
- 主要失败方式：稻草人反方、假平衡、把角色立场当事实；可逆性：高；失败门：没有可验证反方或不影响决定。
- 恢复路径：保留一个最强证据缺口，转 P3 取证或普通路径。

## 组合关系
- 前序：`key-assumptions-check`；后序：`aps-roi-options`；冲突：为形式完整制造伪反方；最多组合深度：2。

## 控制规则
- 继续：反方能改变证据需求或选项排序；降级：一条最强反方；升级：两个完整模型竞争时转 `team-a-team-b`。
- 换路：缺证据转 P3；退出：反方与翻转条件自足；翻转条件：反方被直接证据排除。

## 有效性证据
- 来源等级：本次直接验证＋一手来源核验；能力证据等级：M1 当前交付验收；适用环境：Agent 系统高影响产品决定的反方论证。
- 成功样本：[关联 Eridanus117/agent-control#109（三方审阅机制方案）的成型方案](https://github.com/Eridanus117/agent-control/issues/109#issuecomment-5260729739)及[决定回执](https://github.com/Eridanus117/agent-control/issues/109#issuecomment-5260909104)；样本摘要：在三方审阅机制整包方案已经明显收敛到 A 窄边界时，方案完整构造“负责人直接决定更低成本、三票可能只是伪独立”的最强可信反方，说明该反方适用的低频低价值边界，列出维持现状的普通路径、负责人注意力代价与可观察翻转条件；负责人随后直接复核并批准推荐 A，没有把反方误写成授权或伪造平衡。原评论没有声明加载本卡，本次只按完整执行形状与负责人复核认定自然样本，不证明卡片事前触发。
- 失败样本：无系统记录；未知：该反方是否实际降低确认偏差，以及在非 Agent 系统、非产品决定场景中能否取得相同决策增益。

## 维护
- 失效条件：来源方法、APS P4 选择边界或负责人决定协议改变；下次最少复核：下一次反方改变证据需求、选项排序或最终推荐时。
- 替代者：`key-assumptions-check`；选择级别：APS 只可在 Agent 系统高影响产品决定的反方论证这一相同边界下建议。
