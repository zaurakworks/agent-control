# APS 父目标验收

## 身份与来源
- `method_id`：`aps-parent-goal-acceptance`；版本：`0.1.0`；维护者：agent-plugins。
- 来源：[APS 里程碑验收协议](../../milestone-acceptance.md)；许可／私域：仓内自有，公开可移植；核验时间：2026-08-11。

## 目的与类型
- 要减少的未知／决定：判断多交付件或长期行为能力是否真实改善父目标，而非只完成计划；主类型：P2；次类型：P4、P5。
- 预期效果：明确父目标贡献、能力回退、证据等级、负责人可见 ROI、完成边界与持久行为入口。

## 进入条件
- 可观察信号：Agent 系统 MVP、工作流替代、高价值父任务或长期行为能力准备宣称完成／采用；前置证据：所有交付事实与基线。
- 输入：父目标成功条件、被替代能力、证据、审阅面；工具／上下文：必要时需要未参与者只读复核。

## 硬门与禁用
- 明示同意：内部验收无需；授权：产品采用、长期依赖与父目标满足仍归负责人。风险／写入所有权：验收者只读，回写须有合同。
- 不适用：普通单 PR、低风险且不改变长期行为的任务只做 APS 五项短检查。

## 执行定义
- 步骤／执行资产：逐项检查父目标贡献、能力回退、证据阶梯、负责人可见 ROI、完成结论与持久入口；同源盲区高时路由独立复核。
- 输出：`revise`／需负责人决定／证据不足及下一所有者；完成条件：六项都有证据或显式缺口。

## 成本画像
- 墙钟：20–90 分钟；Token／工具调用：中至高；协调 Agent：0–1；负责人问询：0–1；维护成本：中。

## 风险与回退
- 主要失败方式：子项完成冒充父目标满足、静默能力回退、证据说高、页面存在冒充 Agent 能力；可逆性：中；失败门：缺基线或当前证据不可取得。
- 恢复路径：降级完成结论，列缺口与下一所有者，保持产品决定未成立。

## 组合关系
- 前序：各交付验证；后序：`aps-alignment-questioning`（确需负责人决定时）；冲突：实现参与者冒充独立父目标复核；最多组合深度：2。

## 控制规则
- 继续：仍有一项长期行为主张未绑定证据；降级：普通五项短检查；升级：产品目标、风险偏好或授权扩大时请求负责人。
- 换路：客观缺口直接修订；退出：六项证据／缺口齐；翻转条件：新证据改变能力回退或证据等级。

## 有效性证据
- 来源等级：本次直接验证；能力证据等级：M0 实现完成；适用环境：长期行为与高价值父任务验收。
- 成功样本：现行入口要求长期行为完成前调用，但本卡尚无独立自然样本台账；失败样本：无系统记录；未知：是否降低父目标误报。

## 维护
- 失效条件：APS 六项父目标验收或证据阶梯改变；下次最少复核：每个高价值父目标验收后。
- 替代者：普通五项短检查；选择级别：人工点名或 APS 明示“未验证”后建议。
