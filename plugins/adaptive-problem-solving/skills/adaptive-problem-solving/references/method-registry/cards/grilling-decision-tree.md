# Grilling 决定树盘问

## 身份与来源
- `method_id`：`grilling-decision-tree`；版本：`0.1.0`；维护者：agent-plugins。
- 来源：仓内 `grilling` `0.1.0`；许可／私域：MIT，能力级独立摘要，不复制上游原文；核验时间：2026-08-11。

## 目的与类型
- 要减少的未知／决定：沿决定依赖逐轮压力测试计划、决定或想法；主类型：P2；次类型：P1、P5。
- 预期效果：形成清楚的共同理解，同时把事实调查与价值决定分开。

## 进入条件
- 可观察信号：用户直接要求 grilling／盘问／压力测试，或明确接受此前一次建议；前置证据：可描述的新不确定性或风险。
- 输入：待测试对象、现有决定、范围；工具／上下文：事实优先由 Agent 用官方来源和工具查明。

## 硬门与禁用
- 明示同意：**必须**；关键词、复杂度、索引命中、M1 或 Agent 偏好均不是同意。授权：方法同意不产生实施授权。
- 风险／写入所有权：实施前再次确认共同理解；不适用：用户选择普通路径、剩余问题价值低或事实尚可由 Agent 自查。

## 执行定义
- 步骤／执行资产：调用 `grilling` Skill；按前置决定已确定的 frontier 分轮提问，独立问题同轮，依赖问题延后；每问给建议。
- 输出：已确认决定、替代方案、未知与下一路径；完成条件：重要分支收敛并获实施前确认。

## 成本画像
- 墙钟：15–60 分钟；Token／工具调用：中；协调 Agent：0–1；负责人问询：多轮；维护成本：低。

## 风险与回退
- 主要失败方式：无同意启动、重复建议、把事实反问用户、提问税过高；可逆性：高；失败门：用户拒绝／退出或剩余价值低于成本。
- 恢复路径：停止剩余问题，交接原任务、已确认决定、未知与普通路径。

## 组合关系
- 前序：`aps-alignment-questioning`（只可建议）；后序：`aps-roi-options`；冲突：无同意时与任何自动启动冲突；最多组合深度：1。

## 控制规则
- 继续：本轮问题处于已解锁 frontier 且会改变决定；降级：一次最小问题；升级：新事实打开高价值分支。
- 换路：调查事实转 P3；退出：用户选择普通路径或成本门命中；翻转条件：用户撤回同意、对象已足够清楚。

## 有效性证据
- 来源等级：本次直接验证；能力证据等级：M0 实现完成；适用环境：用户明确同意的结构化压力测试。
- 成功样本：当前权威记录的最小双端安装与恢复验收只证明资产可发现，不证明方法效果；失败样本：无系统记录；未知：自然任务中对决定质量的增益。

## 维护
- 失效条件：`grilling` 同意、退出或实施前确认合同改变；下次最少复核：Skill 版本变化或任何同意门事故后。
- 替代者：`aps-alignment-questioning`；选择级别：人工点名或 APS 明示“未验证”后建议，未获同意始终不得运行。
