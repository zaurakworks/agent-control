# 多视角攻防复核

## 身份与来源
- `method_id`：`multi-perspective-adversarial-review`；版本：`0.2.0`；维护者：agent-plugins。
- 来源：[APS 攻防协议](../../adversarial-review.md)与[关联 #100（夜间新增资产攻防审计）C7 裁决](https://github.com/Eridanus117/agent-control/issues/100#issuecomment-5259393664)；许可／私域：仓内自有，公开可移植；核验时间：2026-08-12。

## 目的与类型
- 要减少的未知／决定：选择独立上下文攻击高影响对象；主类型：P4；次类型：P5；预期效果：减少同源盲区。

## 进入条件
- 可观察信号：对象明确且选错损失高于协调成本；前置证据：可攻击模型与重型协作授权；输入：对象、攻击面、成本上限；工具／上下文：独立 Session 与协调后端。

## 硬门与禁用
- 明示同意：无需用户参与问询，须已有多 Agent 委派；授权：候选不产生实施权；风险／写入所有权：视角和写回排他；不适用：低风险、对象不清或净收益为负。

## 执行定义
- 步骤／执行资产：只执行上述 APS 攻防协议；本卡不复制轮次、评论结构、裁决或停止步骤。输出与完成条件：以该协议为准；角色与交付适配按 CF-5。

## 成本画像
- 墙钟：1–2 波次；Token／工具调用：高；协调 Agent：至少 4；负责人问询：通常 0；维护成本：中。

## 风险与回退
- 主要失败方式：选择门未成立却误用重型形状；可逆性：中；失败门：对象被证伪、授权失效或成本超门；恢复路径：退回 P1 或 APS 轻量预演。

## 组合关系
- 前序：`aps-problem-modeling`、`premortem`；后序：`aps-roi-options`；冲突：参与拆分者冒充独立复核；最多组合深度：2。

## 控制规则
- 继续：选择门成立；降级：轻量预演；升级：证据缺口转 P3；换路：对象被证伪转 P1；退出：APS 停止门；翻转条件：净收益转负或授权失效。

## 有效性证据
- 来源等级：一手来源核验；能力证据等级：M0 实现完成；适用环境：高影响 Agent 系统权威与 Skill 审计。
- 被验收主张：当前文字自洽可执行；成功样本：尚无足以绑定完整合同的样本。[关联 #66（权威与 Skill 资产攻防审计）](https://github.com/Eridanus117/agent-control/issues/66)只有一条第二轮裁决评论，未达到当前至少两名裁决者的下限。失败样本：无独立完整记录；未知：跨对象净收益。

## 维护
- 失效条件：APS 选择门、执行或停止合同改变；下次最少复核：下一自然重型波次的收益、成本与失败；替代者：`premortem`；选择级别：M0，仅人工点名或 APS 明示未验证后建议。
