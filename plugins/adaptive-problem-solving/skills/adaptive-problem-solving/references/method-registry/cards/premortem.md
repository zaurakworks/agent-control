# 已失败假定预演（Premortem）

## 身份与来源
- `method_id`：`premortem`；版本：`0.1.1`；维护者：agent-plugins。
- 来源：[APS 攻防协议的轻量前置](../../adversarial-review.md#轻量前置)；外部结构由旧仓 [Eridanus117/agent-control#70（方法模型与方法库的目标形态）](https://github.com/Eridanus117/agent-control/issues/70)所核验的 CIA 结构化分析资料校准；许可／私域：独立改写，未复制来源原文；核验时间：2026-08-11。

## 目的与类型
- 要减少的未知／决定：在重要合同或方案实施前暴露最可能失败原因；主类型：P4；次类型：P5。
- 预期效果：为每个高价值失败原因配上缓解、责任人与停止信号。

## 进入条件
- 可观察信号：对象已明确，失败代价高于 10–20 分钟预演成本；前置证据：成功条件、边界和责任人。
- 输入：计划／合同、时间盒；工具／上下文：单 Session 即可。

## 硬门与禁用
- 明示同意：内部自审无需；对用户开启问询仍需其同意。授权：预演不改变合同与实施权。
- 风险／写入所有权：只读检查；对象暂停或等待决定时，只登记恢复后的候选动作，不把风险发现解释为恢复、催办或扩大写入权；不适用：对象尚未成形、低风险机械步骤或无责任人可承接缓解。

## 执行定义
- 步骤／执行资产：假定对象已经失败，独立列出原因，以证据锚点、可能性、影响与可控性筛选，逐项对照现有缓解和剩余缺口，再给出可观察信号与责任人，时间盒到点收口。
- 输出：按任务裁剪的失败路径表；现有缓解与剩余缺口成对出现。完成条件：至少覆盖最高价值失败路径，或明确没有新增攻击。

## 成本画像
- 墙钟：10–20 分钟；Token／工具调用：低；协调 Agent：0；负责人问询：0；维护成本：低。

## 风险与回退
- 主要失败方式：泛化成风险清单、用想象代替证据；可逆性：高；失败门：原因没有证据锚点、不能改变合同或验证、不可行动，或时间盒用尽；只有想象支撑的原因降级为未知，不进入高优先级表。
- 恢复路径：只保留一条最高影响且可控的缓解，其他作为未知。

## 组合关系
- 前序：`aps-problem-modeling`；后序：`preregistered-experiment-card`；冲突：对象不清时与预演冲突；最多组合深度：2。

## 控制规则
- 继续：新增失败路径能改变设计或验证；降级：一条最高风险；升级：高影响且视角同源时转多视角攻防。
- 换路：缺事实转 P3；阶段合同不明确时转问题建模；失败原因需要跨专业独立判断时升级多视角攻防；退出：时间盒或收益门命中；翻转条件：缓解成本高于预期损失。

## 有效性证据
- 来源等级：本次直接验证＋一手来源核验；能力证据等级：M1 当前交付验收；适用环境：重要但可逆的方案自审。
- 成功样本：[关联 Eridanus117/agent-control#85（Premortem 方法卡实战）的证据升级评论](https://github.com/Eridanus117/agent-control/issues/85#issuecomment-5258420709)；样本摘要：在真实但仍暂停的知识库迁移计划上，以 20 分钟、零负责人问询的预演形成八条可行动失败路径和五道阶段验收门，复核确认其保持暂停与授权边界并实质改变后续验收。
- 失败样本：无系统记录；未知：这些缓解在真实迁移发生后能否减少返工。

## 维护
- 失效条件：APS 攻防协议的轻量形状改变，或目标环境超出重要但可逆的方案自审；下次最少复核：首个不同边界的自然使用完成后。
- 替代者：`key-assumptions-check`；选择级别：APS 只可在相同边界下建议。
