# 配对观察

## 身份与来源
- `method_id`：`paired-observation`；版本：`0.1.1`；维护者：agent-plugins。
- 来源：[NIST 工程统计手册的配对观察说明](https://www.itl.nist.gov/div898/handbook/prc/section3/prc311.htm)；许可／私域：公开一手来源的能力级独立改写，未复制统计原文或公式；核验时间：2026-08-11。

## 目的与类型
- 要减少的未知／决定：在同一对象、同类任务或前后对应条件下比较两个观察，降低对象差异干扰；主类型：P3；次类型：P6、P5。
- 预期效果：当自然配对成立时，比不相关样本更清楚地解释差异。

## 进入条件
- 可观察信号：每个 A 观察都有自然对应的 B 观察；前置证据：配对键、顺序影响、共同度量与缺失处理。
- 输入：配对样本、度量、干扰条件；工具／上下文：保存每对原始值与上下文。

## 硬门与禁用
- 明示同意：授权内观察无需；授权：不授权敏感数据、生产试验或用户操作。风险／写入所有权：数据权与隔离明确。
- 不适用：配对是人为凑合、顺序效应未记录、样本不可对应或要由小样本作产品采用结论。

## 执行定义
- 步骤／执行资产：预注册配对键和指标；记录每对条件；比较对内差异并保留异常与缺失；先作描述性解释，风险相称时再用统计检验。
- 输出：逐对差异、总体模式、局限与选择含义；完成条件：可说明差异来自做法、条件还是仍未知。

## 成本画像
- 墙钟：1 个自然波次以上；Token／工具调用：中；协调 Agent：0–1；负责人问询：0；维护成本：中。

## 风险与回退
- 主要失败方式：伪配对、顺序偏差、丢弃不利配对、精度幻觉；可逆性：中高；失败门：配对键失效或数据不完整。
- 恢复路径：降级为不配对描述性观察，并明确证据更弱。

## 组合关系
- 前序：`goal-question-metric`、`preregistered-experiment-card`；后序：`aps-roi-options`；冲突：无自然对应时强行配对；最多组合深度：2。

## 控制规则
- 继续：新增配对会改变模式；降级：逐对描述；升级：风险与样本支持时才使用统计检验。
- 换路：无配对转 `comparative-experiment`；退出：决定门／成本门；翻转条件：顺序或条件差异解释了对内差异。

## 有效性证据
- 来源等级：本次直接验证＋一手来源核验；能力证据等级：M1 当前交付验收；适用环境：Windows、目录型 marketplace、精确版本目录与文本 Skill 的 LF 规范化安装验收。
- 成功样本：[关联 Eridanus117/agent-control#44（实施已批准决定与授权内动作）的批次四三端指纹验收](https://github.com/Eridanus117/agent-control/issues/44#issuecomment-5256536380)及本批 `adaptive-problem-solving@0.2.6` 三张方法卡复核；样本摘要：两次任务都先固定目标版本目录、配对键、LF 规范化 SHA-256 与缺失处理，再比较源树、Claude 缓存和 Codex 缓存。前一批四个 Skill 三端一致；本批三张卡六个端点比较 6／6 一致，`high-impact-low-probability`、`paired-observation`、`indicators-signposts` 的哈希分别为 `2ffbd2bc97db8bbc3502f68578924bf80614ccc83b7223b009627f3348843e3e`、`0b34d59769372d4e3a6ea020211522ab6c8852911eb7e637c4175fb5d6d57eea`、`0e28f09508a9913f032bfc0e1dbeeae9d936f6217cc4e7fc2dd80e4b4f1e92bf`。方法把结论从“安装内容不一致”改为“跨版本选择器命中 Claude 旧副本；锁定目标版本后配对有效”。
- 失败样本：[关联 Eridanus117/agent-control#44（实施已批准决定与授权内动作）的指纹勘误](https://github.com/Eridanus117/agent-control/issues/44#issuecomment-5256536380)记录跨版本通配先产生假不一致，并纠正“两端均保留历史版本”为“Claude 保留多版本、Codex 只保留当前版本”；未知：同宿主同类样本尚不能给出异质环境的配对质量、成本或失败分布，证据上限为 M1，不支持 M2。

## 维护
- 失效条件：NIST 来源、配对假设或数据边界改变；下次最少复核：下一次异质宿主或不同安装机制的配对验收后。
- 替代者：`comparative-experiment`；选择级别：APS 只可在 Windows、目录型 marketplace、精确版本目录与文本 Skill 的 LF 规范化安装验收这一相同边界下建议。
