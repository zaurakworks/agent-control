# “如果发生”分析

## 身份与来源
- `method_id`：`what-if-analysis`；版本：`0.1.0`；维护者：agent-plugins。
- 来源：CIA《A Tradecraft Primer》“What If?” Analysis；许可／私域：公开一手来源的独立改写，未复制原文；核验时间：2026-08-11。

## 目的与类型
- 要减少的未知／决定：通过暂时接受一个反常结果，反推其因果路径、早期信号与当前遗漏；主类型：P4；次类型：P1、P3。
- 预期效果：扩大可想象结果空间，同时把想象落回可验证信号。

## 进入条件
- 可观察信号：当前判断高度自信、替代结果被过早排除，且错误代价明显；前置证据：基线结论与被排除结果。
- 输入：反常结果、时间边界、关键参与者／机制；工具／上下文：单 Session。

## 硬门与禁用
- 明示同意：无需；授权：想象不产生实施权或事实结论。风险／写入所有权：只读。
- 不适用：反常结果没有可信因果链、低风险任务或普通实验可直接验证。

## 执行定义
- 步骤／执行资产：假定结果已发生，逆向构造必要事件链与动因，找当前可见但被忽略的信号，比较其与基线证据。
- 输出：替代因果链、信号、脆弱假设与验证动作；完成条件：想象结论被重新标为证据需求而非事实。

## 成本画像
- 墙钟：15–45 分钟；Token／工具调用：低至中；协调 Agent：0；负责人问询：0；维护成本：低。

## 风险与回退
- 主要失败方式：故事替代证据、无限情景、反常结果无边界；可逆性：高；失败门：无法产生任何当前可观察信号。
- 恢复路径：回到基线结论，只保留一项脆弱假设或信号。

## 组合关系
- 前序：`key-assumptions-check`；后序：`indicators-signposts`、`aps-bounded-research`；冲突：把故事当证据；最多组合深度：2。

## 控制规则
- 继续：替代链会改变验证或回退；降级：一个反常结果；升级：多个结构化未来转 `alternative-futures`。
- 换路：可实验转 P6；退出：信号与假设明确；翻转条件：直接证据排除因果链。

## 有效性证据
- 来源等级：一手来源核验；能力证据等级：M0 实现完成；适用环境：高自信、低可逆性的判断。
- 成功样本：本系统尚无；失败样本：无系统记录；未知：对过度自信的实际改善。

## 维护
- 失效条件：来源方法或本系统情景边界改变；下次最少复核：首次自然使用后。
- 替代者：`high-impact-low-probability`；选择级别：人工点名或 APS 明示“未验证”后建议。
