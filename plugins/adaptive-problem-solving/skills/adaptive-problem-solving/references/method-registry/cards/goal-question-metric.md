# 目标—问题—度量（GQM）

## 身份与来源
- `method_id`：`goal-question-metric`；版本：`0.1.1`；维护者：agent-plugins。
- 来源：[NASA Software Engineering Laboratory 的 GQM 资料](https://ntrs.nasa.gov/api/citations/19920008884/downloads/19920008884.pdf)；许可／私域：公开一手来源的独立改写，未复制原文；核验时间：2026-08-11。

## 目的与类型
- 要减少的未知／决定：从明确目标推导可回答问题，再推导最少度量；主类型：P3；次类型：P1、P6。
- 预期效果：避免先收集数据再寻找用途，让每个指标回到决定价值。

## 进入条件
- 可观察信号：需要测量收益／质量／效果，但指标与目标脱节；前置证据：目标、对象、视角与环境边界。
- 输入：目标、成功条件、可得数据；工具／上下文：自然任务数据优先，不新建平台。

## 硬门与禁用
- 明示同意：无需；授权：不授权新监控、问卷、数据库或敏感数据收集。风险／写入所有权：数据访问遵守原边界。
- 不适用：一次观察即可决定，或采集成本高于决定价值。

## 执行定义
- 步骤／执行资产：写目标；推导能判断目标是否进展的问题；为每问选择最少可得指标、解释边界与失败门；预写指标如何改变行动。
- 输出：目标—问题—指标链与采样计划；完成条件：每个指标都绑定一个问题和后续决定。

## 成本画像
- 墙钟：20–60 分钟；Token／工具调用：中；协调 Agent：0–1；负责人问询：0；维护成本：中。

## 风险与回退
- 主要失败方式：指标膨胀、代理指标替代目标、为测量重跑任务、伪精确；可逆性：高；失败门：指标不改变决定或采样税超门。
- 恢复路径：只保留一问一指标，用描述性样本并明确局限。

## 组合关系
- 前序：`aps-problem-modeling`；后序：`preregistered-experiment-card`、`paired-observation`；冲突：无目标的数据收集；最多组合深度：2。

## 控制规则
- 继续：指标会改变是否继续／修改／停止；降级：单一自然指标；升级：因果主张需要实验设计时转 P6。
- 换路：只缺来源事实转受限调研；退出：链条可执行；翻转条件：数据不可得或采集成本转负。

## 有效性证据
- 来源等级：本次直接验证＋一手来源核验；能力证据等级：M1 当前交付验收；适用环境：Agent 系统运营指标的人工低成本基线与复核。
- 成功样本：[关联 Eridanus117/agent-control#79（系统运营指标基线）的调研评论](https://github.com/Eridanus117/agent-control/issues/79#issuecomment-5258121023)及[决定回执](https://github.com/Eridanus117/agent-control/issues/79#issuecomment-5258166941)；样本摘要：从“让资源与运营信号支持真实投入决定”的目标出发，把有用吞吐、负责人注意力、周期、恢复、返工、方法证据与资源容量分解为七个需要回答的观察问题，再为每问定义最少可得指标、基线、数据质量、Goodhart 护栏及改变行动的翻转条件；负责人复核后选择五主两情境、自然回执寄生与三波复核，没有引入仪表盘或自动采集。原评论没有声明加载本卡，本次只按完整执行形状与负责人复核认定自然样本，不证明卡片事前触发。
- 失败样本：无系统记录；未知：三波后记录成本、分母争议和行为副作用是否命中预设翻转条件，以及非 Agent 系统运营场景能否复现。

## 维护
- 失效条件：NASA 来源水位、目标、数据边界或首批运营口径改变；下次最少复核：三波人工观察结束，或记录成本与行为副作用先命中翻转条件时。
- 替代者：单次任务验证；选择级别：APS 只可在 Agent 系统运营指标的人工低成本基线与复核这一相同边界下建议。
