# APS 攻防与反证

## 身份与来源
- `method_id`：`aps-adversarial-falsification`；版本：`0.1.0`；维护者：agent-plugins。
- 来源：[APS 攻防协议](../../adversarial-review.md)；许可／私域：仓内自有，公开可移植；核验时间：2026-08-11。

## 目的与类型
- 要减少的未知／决定：发现能推翻当前问题定义、模型或方案的可信反例；主类型：P4；次类型：P1、P5。
- 预期效果：在高损失错误进入共享状态前暴露假设、失败路径与替代解释。

## 进入条件
- 可观察信号：对象已经明确、隐藏假设可能造成高损失；前置证据：可被攻击的问题定义、方案或合同。
- 输入：对象、成功条件、主要假设；工具／上下文：轻量可单 Session，重型需要真实独立上下文。

## 硬门与禁用
- 明示同意：内部轻量检查无需；重型多 Session 需有协作与写入分区授权。授权：攻防结论不产生实施权。
- 风险／写入所有权：每个视角只读或排他写回；不适用：对象尚未写清、普通低风险步骤或协调成本高于选错损失。

## 执行定义
- 步骤／执行资产：先轻量预演；仅在启动判据成立时用 `premortem` 或 `multi-perspective-adversarial-review`。
- 输出：可信攻击、缓解、失效条件与待实验未知；完成条件：停止判据命中并把结论带回原任务。

## 成本画像
- 墙钟：10 分钟至 2 轮；Token／工具调用：中至高；协调 Agent：0 或 2+；负责人问询：通常 0；维护成本：中。

## 风险与回退
- 主要失败方式：没有靶子的自我红队、把怀疑当事实、重型流程误触发；可逆性：中高；失败门：新一轮不再改变决定或对象被证伪。
- 恢复路径：退回 P1 重建对象，或只保留一条最高价值攻击与缓解。

## 组合关系
- 前序：`aps-problem-modeling`、`key-assumptions-check`；后序：`aps-roi-options`、`preregistered-experiment-card`；冲突：对象不清时与重型攻防冲突；最多组合深度：2。

## 控制规则
- 继续：攻击仍能改变决定；降级：单 Session 预演；升级：高影响且协作净收益为正时多视角。
- 换路：对象被证伪转 P1；退出：停止判据命中；翻转条件：可逆试验比继续攻击更快。

## 有效性证据
- 来源等级：本次直接验证；能力证据等级：M0 实现完成；适用环境：高影响合同、方案与父目标。
- 成功样本：路线级样本尚未单独登记；失败样本：无系统记录；未知：轻重分级的自然误触发率。

## 维护
- 失效条件：APS 攻防协议或其轻重形状被替代；下次最少复核：任何高损失误触发后立即复核。
- 替代者：`key-assumptions-check`、普通自审；选择级别：人工点名或 APS 明示“未验证”后建议。
