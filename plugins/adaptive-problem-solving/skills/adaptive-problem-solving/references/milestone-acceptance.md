# 里程碑与最终验收

> 仅在长程 Agent 能力、工作流替代、父任务或其他长期行为进入自然里程碑或最终验收时加载。普通、低风险、可回退且不改变长期行为的任务不加载。完成后返回 `../SKILL.md`。

按行为影响而不是交付件数量检查六项，不能用子任务或计划完成度替代：

1. **父目标贡献**：整体实际改善原始问题和父目标的哪一部分；只确认子任务或计划完成不算通过。
2. **能力回退**：对照当前基线、参考能力和被替代方案，列出保留、删除或弱化；后两者必须有证据且被有意接受，不能静默丢失。
3. **证据等级**：明确当前证据最多支持哪一级，不把低一级说成高一级：

   ```text
   实现完成 → 当前交付验收 → 样本有效 → 产品采用 → 长期依赖
   ```

   箭头只表示证据增强，不是流程或目标；每一级各需证据，前一级不自动解锁后一级。产品采用和长期依赖还需要负责人决定。
4. **负责人可见 ROI**：需负责人决定时，收益、成本、失败、限制、可信替代、推荐和待决定事项必须进入其可直接访问的审阅面；聊天、终端、本地文件或研发记录不算。
5. **完成结论**：写清实际完成、缺口和下一责任人；不把动作已执行写成方案已可用。
6. **持久行为入口**：声称能力可跨 Session／模型复用时，指出持久触发、行为载体、真实入口和可发现性证据；文件、Issue、脚本或缓存本身不证明行为已接入，人工运行就如实标明。

参与建模、拆分或设计者存在同源盲区。需要未参与者做父目标级只读复核时，路由 `orchestrated-collaboration`，不在 APS 内自建审查角色或评测平台。

## 缺口归属

- **授权内客观缺口**：能力静默丢失、证据等级过高、审阅面缺失、结论与证据不符时判定 `revise`，直接修正或提出最小方案后继续；
- **产品目标与取舍、风险偏好、扩大授权**：先运行 G2，再合并成一次负责人决定；
- **只影响 Agent 自加假设**：记录后继续。

没有完成父目标贡献和能力回退检查之前，不得声称父目标或产品闭环完成。
