# 入口调用文本提议（草稿）

> 本文件只是供入口拼接者采用的草稿；本交付不修改 `AGENTS.md`、`entrypoints/agent-system.md` 或全局 `CLAUDE.md`。

## 建议文本

当 Session 开始 Agent 系统工作，以及首次准备修改可能与其他 Session 重叠的共享目录、分支、当前任务、权威、用户级 Agent 配置、已安装 Skill／Plugin 或 Orca 状态前，运行：

```powershell
python tools/sibling-facts/sibling_facts.py
```

把输出当作当时的只读观察事实，不当作授权或所有权。逐项查看「谁／写哪儿／怎么核实」；发现潜在重叠、`orphaned=true`、来源「未观察到」或事实互相冲突时，先执行该项给出的确切命令复核，再按现有共享写入与协作规则取得明确分区。方向未变且同阶段没有新的活动事实时不重复调用；进入新阶段、恢复长任务、接到新 Dispatch，或准备首次触及新的共享范围时重新调用。

## 调用位置理由

- 启动时给出兄弟事实，避免把发现责任留给 Session 自觉；
- 写入前再刷新，覆盖启动后才出现的 Session；
- 不做 Hook、不自动处置、不持续轮询，保留工具的查询边界；
- 易变清单留在每轮调用输出，不写进稳定入口正文。
