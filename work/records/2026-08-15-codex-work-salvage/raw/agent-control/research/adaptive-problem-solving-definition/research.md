## 来源与事实

### 1. Nelson 与 Narens：元认知的监测—控制框架（1990）

来源：[Metamemory: A Theoretical Framework and New Findings（论文 PDF）](https://pdf.retrievalpractice.org/metacognition/4_Nelson_Narens_1990.pdf)

- 框架区分元层和对象层。监测是信息从对象层流向元层，更新元层对当前状态的模型；控制是元层改变对象层的状态或过程。
- 控制动作可以开始、继续或终止对象层行动；监测本身不等于控制。
- 文中把目标、计划、学习时间分配、策略选择和搜索终止列为不同的监测或控制成分。
- 作者明确不假定主观内省准确；主观报告被当作对内部过程的“不完美测量”。这项事实直接限制了“Agent 说自己在反思”能提供的证据强度。

### 2. Shenhav、Botvinick 与 Cohen：控制的预期价值（2013）

来源：[The Expected Value of Control（论文 PDF）](https://www.princeton.edu/~ashenhav/Publications_Presentations_files/Neuron%202013%20Shenhav.pdf)

- 该规范模型把控制分配描述为一个净价值计算：综合预期收益、实现收益所需的控制强度，以及认知努力成本。
- 模型要回答是否分配控制、把控制分配到哪里、分配多少；它把这个选择与具体执行控制的机制区分开。
- 论文对象是人类认知控制及相关脑区功能，不是 Agent 产品架构，也不直接定义跨任务方法保存。

### 3. Lieder 与 Griffiths：资源理性分析（2020）

来源：[Resource-rational analysis（论文及同行评议 PDF）](https://cocosci.princeton.edu/papers/liederresource.pdf)

- 该方法把理性原则与时间、认知资源和可用操作等现实约束结合，用于建立认知过程模型。
- 作者把它明确描述为研究者使用的建模方法，而不是一套已经完整展开的人类认知理论。
- 其五步过程从功能定义和计算架构假设出发，推导算法、用数据检验预测，再据此修正假设；停止于预测足够准确或相关约束已被合理纳入。
- 论文同时指出：在环境或认知约束未知时应用困难；完整理论还需要解释主体怎样学会更合理地使用有限资源。
- 同卷同行评议进一步区分了“研究者使用这种方法建模”与“人本身实际上资源理性”两个命题，指出前者不能自动证明后者。

### 4. IBM：MAPE-K 自主管理控制环（2004）

来源：[On the design of a self-managing storage system（IBM Research 报告）](https://dominoweb.draco.res.ibm.com/reports/h-0219.pdf)

- 该架构把受管元素与自主管理器分开；自主管理器通过传感器收集状态，通过执行器改变受管元素。
- 控制环分为监测、分析、计划和执行，四部分共享知识。
- 其原始问题域是降低 IT 系统管理复杂度。这个结构描述运行时闭环，但来源没有把“重新界定目标”或“跨任务淘汰思考方法”定义为环内必备能力。

### 5. Argyris：单环与双环学习（1977）

来源：[Double Loop Learning in Organizations（HBR 原文产品页）](https://store.hbr.org/product/double-loop-learning-in-organizations/77502)

- 该文把组织学习定义为发现并纠正错误。
- 单环学习是在既定目标下纠正问题；双环学习允许纠错时质疑底层政策和目标。
- 原始对象是组织及其阻碍公开错误的行为规范。这个区分涉及目标或规则能否被修改，但没有描述完整的任务执行控制环。

### 6. Schön：行动中反思（1983/1984 版）

来源：[The Reflective Practitioner（出版社页面）](https://www.hachettebookgroup.com/titles/donald-a-schon/the-reflective-practitioner/9780465068784/)

- 该书研究专业人员实际怎样解决问题，强调他们面对实践挑战时使用的即兴判断，而不只是套用学校中学习的公式。
- 出版社把其主题概括为“行动中反思”：反思发生在实践过程内，而不只发生在事后。
- 当前可访问的一手页面只提供书籍概述，不能据此确认它是否包含成本分配、可执行停止条件或跨任务方法淘汰机制。

### 7. ReAct：把语言推理与环境行动交错（2022/2023）

来源：[ReAct: Synergizing Reasoning and Acting in Language Models（arXiv 论文）](https://arxiv.org/abs/2210.03629)

- ReAct 在一条任务轨迹中交错生成语言推理、行动和环境观察。推理用于建立、跟踪和调整计划以及处理异常；行动用于从外部环境获得新信息。
- 论文显示了这种交错机制在若干问答、事实核验和交互决策基准上的效果，同时报告了幻觉行动、复杂轨迹推理失败以及小模型难以从上下文样例学会双重行为等限制。
- 试验中的模型主要是冻结参数的 LLM；这个机制本身没有跨任务修改或淘汰方法库。

### 8. Reflexion：反馈、语言反思与情节记忆（2023）

来源：[Reflexion: language agents with verbal reinforcement learning（NeurIPS 论文页）](https://papers.neurips.cc/paper_files/paper/2023/hash/1b44b878bb782e6954cd888628510e90-Abstract-Conference.html)

- Reflexion 不通过更新模型权重学习，而是让 Agent 针对任务反馈产生语言反思，并把反思文本放入情节记忆，用于之后的尝试。
- 反馈可以是数值或自由文本，来源可以是外部，也可以是内部模拟。
- 论文的实证对象是特定的顺序决策、编程和语言推理任务；来源没有将所有被保存的反思都证成可靠的通用方法。

### 9. Voyager：环境验证后的可执行技能积累（2023）

来源：[Voyager 官方项目页](https://voyager.minedojo.org/)

- Voyager 是 Minecraft 中的终身学习 Agent，包含自动课程、可执行代码技能库和迭代提示三个主要部分。
- 迭代提示使用环境反馈、执行错误和自验证改进程序；掌握后的技能以代码存入库，按描述检索，并可组合为更复杂的技能。
- 论文报告技能库可在新 Minecraft 世界中复用。这是特定世界内的可执行行为复用证据，不等于任意问题的思考方法都能跨领域传递。

### 10. Anthropic：Agent 工程中的反馈闭环与成本边界（2024）

来源：[Building effective agents（Anthropic Engineering）](https://www.anthropic.com/engineering/building-effective-agents)

- 该文区分预定代码路径的工作流与由 LLM 动态决定过程和工具使用的 Agent。
- 其 Agent 描述以环境反馈形成循环，要求在执行中从工具结果或代码执行等环境事实判断进展；Agent 可在检查点或阻塞时请求人类反馈，并使用最大迭代次数等停止条件。
- 其“评估者—改进者”工作流以明确评估标准和可测量的迭代价值为适用条件，不是默认对所有任务启用。
- 该文记录的工程取舍是：Agent 通常以更高延迟、成本和误差累积风险换取弹性；增加复杂性需要有可演示的结果改善。
- 对编程 Agent，测试结果可验证功能，但文章明确区分了这种验证与更广义需求对齐；后者仍需人类审查。

### 11. Huang 等：无外部反馈的内在自我纠错（2023）

来源：[Large Language Models Cannot Self-Correct Reasoning Yet（Google DeepMind 发布页）](https://deepmind.google/research/publications/48252/)

- 论文把“内在自我纠错”限定为 LLM 只依靠自身能力、没有外部反馈地修改初始答案。
- 在论文研究的推理任务上，LLM 难以稳定自我纠错，纠错后性能有时下降。
- 这个结论的明确适用范围是“无外部反馈的推理自我纠错”，不是对所有含工具、验证器或人类反馈的纠错方式作广义否定。

### 12. CRITIC：用外部工具反馈纠错（2023/2024）

来源：[CRITIC: Large Language Models Can Self-Correct with Tool-Interactive Critiquing（ICLR 论文页）](https://proceedings.iclr.cc/paper_files/paper/2024/hash/fef126561bbf9d4467dbb8d27334b8fe-Abstract-Conference.html)

- CRITIC 让 LLM 使用搜索、代码执行等工具检查初始输出的特定方面，再基于工具反馈修改输出。
- 论文在自由问答、数学程序生成和有害内容降低任务上报告了性能改善，其证据支持外部反馈对这些类型纠错有用。
- 这些实验没有证明工具反馈必然覆盖用户真实意图、需求边界或方法是否值得跨任务保留。

## 概念覆盖比较

> 下表是对上述原始来源覆盖范围的归纳，不表示可以把人类认知理论直接当作 Agent 架构。

| 概念族 | 实际覆盖 | 不直接覆盖 |
| --- | --- | --- |
| 元认知监测—控制 | 用对象层信息更新元层模型，再开始、继续、调整或终止行动 | 如何选对监测信号；如何证明自我判断准确；跨任务资产治理 |
| 控制价值／资源理性 | 把改进收益、所需控制量、时间或认知成本纳入计算 | 不自动提供真实效用、成本或可用策略的数值；不是完整求解流程 |
| 行动中反思 | 在实践内面对非常规情况即兴判断，而非只套用预设公式 | 当前一手概述不足以确认成本、停止或跨任务保留机制 |
| 单环／双环学习 | 区分在既定目标下纠错，与连底层政策和目标一起质疑 | 不是实时任务控制架构；不定义具体方法库或 Agent 运行方式 |
| MAPE-K | 受管系统的监测、分析、计划、执行和共享知识 | 原始范围是 IT 系统自主管理；不要求重新定义人的目标 |
| ReAct | 单次任务中用外部观察更新计划、处理异常和继续行动 | 不保存或评估跨任务方法 |
| Reflexion | 把任务反馈转成语言反思，通过情节记忆影响后续尝试 | 不证明反思文本必然真实、通用或值得长期保留 |
| Voyager | 把经环境执行改进后的代码行为存为可检索、可组合技能 | 实证是 Minecraft 领域内迁移，不是任意思考方法的跨域验证 |
| 工业 Agent 反馈环 | 从工具或执行结果获得环境事实，以检查点、人类反馈和停止条件控制长程执行 | 功能测试不等于需求对齐；自主性带来成本和误差累积 |
| LLM 纠错实证 | 无外部反馈的内在纠错不稳定；特定任务上，工具反馈可帮助检查和修改 | 不能由局部基准推出所有任务、用户意图或方法升级都可自动验证 |

### 对“双循环”工作假设的事实性攻防

以下是基于上述来源的归纳性判断，不是产品定义：

- **有来源支持的部分**：任务内“观察→调整”对应元认知监测—控制、MAPE-K 和 ReAct 中的不同结构；跨尝试保留反思或可执行技能分别在 Reflexion 和 Voyager 中有实例。
- **当前表述混在一起的层次**：对当前进度的监测、对具体计划的调整、对目标或规则的质疑、对增加思考成本的价值判断，在原始来源中是不同问题，而“任务内调整求解方式”会同时指向它们。
- **跨任务循环混在一起的对象**：一次尝试的反思文本、已执行的领域技能、事实知识、通用思考方法和系统规则不是同一类资产；这些来源没有给出一个共同的保留与淘汰机制。
- **结果不是单一信号**：来源中分别出现任务奖励、自动测试、工具返回、环境执行、人类反馈、需求对齐、延迟和成本。“根据真实效果”本身并未区分哪个信号对哪种判断有效。
- **重新界定问题尚未被完整解释**：双环学习提供了质疑目标和政策的区分，行动中反思覆盖实践内即兴调整；本轮来源没有提供一个已验证的、同时适用于人机长程任务的“何时重新界定原始问题”机制。
- **没有单一上位概念被证实覆盖全部能力**：“元认知”、“反思实践”、“双环学习”、“资源理性”、“自主控制环”和各类 LLM Agent 机制分别覆盖不同切面。

## 可观察信号与限制

上述来源中实际使用或明确区分的信号包括：

- **环境信号**：工具返回、检索到的外部信息、编译或执行错误、测试结果、游戏世界状态。
- **任务结果**：是否完成、基准分数、成功率、任务奖励、新任务中的复用表现。
- **过程行为**：采取了哪些行动、何时改计划、何时请求人类判断、何时停止、实际用时与迭代次数。
- **人类信号**：明确反馈、检查点决定、验收以及对更广义需求的审查。
- **资源信号**：延迟、迭代或认知努力成本，以及预期改善。

局限：

- 自由文本的“思考过程”、信心声明、原因解释和“我已经学会”都是 Agent 的输出，不是独立的结果验证。
- Nelson 与 Narens 把人的内省报告当作不完美测量；Huang 等的结果又表明 LLM 在无外部反馈时的推理纠错不稳定。两者研究对象不同，但都不支持把自我描述等同于准确监测。
- 外部信号也只验证它能覆盖的属性：测试可验功能，但不自动验证需求对齐；人类当次验收不自动证明方法在未来任务中可迁移。

## 约束

- 本轮在第 12 个来源后按预设来源数停止，不再扩展概念族。
- 人类认知、组织学习、IT 系统控制和 LLM Agent 论文的研究对象不同；本文只比较它们明示的功能分工，不把它们当作可直接互换的实现。
- 实证结果只适用于各论文实际测试的任务、模型和反馈条件，不外推为通用 Agent 能力。
- HBR 双环学习的正文受访问限制；本轮只使用原文官方产品页明示的概念区分。Schön 部分也只使用出版社概述可确认的事实。

## 未知

- 本轮未验证一个成熟概念能单独覆盖：原始问题重新界定、方法选择、成本控制、人机对齐、任务执行，以及跨任务方法治理。
- 本轮没有获得通用、已验证的“何时应重新界定问题”触发信号或阈值。
- 本轮没有获得将一次有效干预升级为通用方法、Skill 或规则的通用证据标准。
- 本轮没有深入核验“自适应专长（adaptive expertise）”、自我调节学习或其他相邻教育心理学概念；因来源数已达停止条件，它们仍是未核验的相邻词，不构成当前定义的支持或反证。
