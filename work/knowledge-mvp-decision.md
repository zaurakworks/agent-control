# 知识系统 MVP 决策

> 状态：负责人已选择 1；本页仍是决策过程记录，不是知识。
> 详细依据：[`knowledge-mvp-proposal.md`](./knowledge-mvp-proposal.md)

## 要验证什么

把已经完成的调研保存成可直接使用的可信内容。后续先读它，只核验变化和缺口；总成本应低于重新调研。

## 推荐方案：K1 可信知识包

每个知识包至少包含：

- 回答的问题和适用范围；
- 可直接复用的结论；
- 每项重要结论的第一方来源或实验依据；
- 最后核验日期和版本；
- 已知未知项；
- 失效条件；
- 下次复用时最少检查什么。

未通过可信门槛的内容不进入知识区，只能留在工作记录或被丢弃。失效内容也不继续作为当前知识。

## 为什么不选另外两个方案

- 只保存来源入口：后续仍要重新阅读，复用价值太低；
- 保存完整来源、复杂结构或知识图谱：当前建设和维护成本过高。

## 首个主题

Codex `AGENTS.md` 与 Claude Code `CLAUDE.md` 的项目指令加载规则。

这个主题已经完成官方资料核验、范围小、会被后续配置工作复用，也有清楚的失效条件。

## 存放边界

首次只创建：

```text
work/knowledge-trial/project-instructions.md
```

它在试用通过前不是正式知识。当前不创建正式 `knowledge/` 目录，不决定知识仓是否与控制仓合并。

## 本次不做

- 不建设正式知识库或新仓库；
- 不吸收旧知识；
- 不保存完整网页；
- 不做自动检索、自动更新或知识图谱；
- 不处理私域内容；
- 不进行新的大规模调研。
